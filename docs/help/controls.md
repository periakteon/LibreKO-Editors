# Editor controls and troubleshooting

1. Use Home or the header selector to switch Content, Events and Map & NPC while retaining the shared connection. Header Back/Forward or Alt+Left/Right retraces related records, source documents and view context. History opens saved-change/recovery operations, a separate feature.
2. Use Ctrl+S to review/save, Ctrl+Z/Y to undo/redo and Ctrl+F to search the current editor. Unsaved navigation offers Save, Discard or Cancel. F1 or Help opens this guide without changing the draft.
3. In Player characters, drag inventory icons to move/swap; click an empty slot or Compatible items to search valid items; hover for details. Account role, Knight Cash and premium settings live in Accounts and affect all linked characters.
4. In Map & NPC, select a zone and click a related spawn to focus that exact point. NPC/monster placement rows include zone, coordinates, count and respawn. Show on map follows the selected placement. Content Items has Origins for sellers and direct/pool drops.
5. Right-drag the map to orbit, middle-drag to pan and use the wheel to zoom. Top view looks down; Focus selected frames a marker. Fly camera uses W/A/S/D and Q/E while the map has focus. Grid snap rounds moved positions; Ground snap follows available terrain. Hover a control or open Controls for details.
6. Expand map hides surrounding panels; Full screen or F11 changes window mode. Escape exits expanded/full-screen editing while retaining camera and draft. Global and panel spinners indicate active work; wait for the load or cancel an operation before editing its stale results.
7. Use the NPC Shop & loot tab beside its 3D model. Drag named item icons into merchant/loot/pool slots, inspect chance values, and review Shared users. Loot-slot swaps retain chance; pool order and duplicate members matter. Merchant stock uses source-file review, not database-only save.
8. Close document or Return to database leaves the source page through its dirty-draft guard. Captured previews have their own Close button, Escape and window close; closing a preview does not close the editor.
9. For missing visuals, select the matching installed client in Settings and run Compatibility. Missing icons/models/effect descriptors can be an incomplete or mismatched build; database edits cannot recreate those files. Inspect findings and source dependencies before running any external asset pipeline. Preserve originals and use staging output.
10. If a field is read-only, inspect Compatibility, the named reference and source provenance. Custom unsupported schema/binary formats are not made writable by dismissing a warning. On save conflict or unknown result, inspect History and reopen current data before retrying.

Help lists your selected database and source roots for orientation. It does not display passwords or certify production identity. Production workflows are in the other topics and are also available as Markdown files in the package's help directory.
