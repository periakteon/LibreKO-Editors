# LibreKO Editors

Standalone Windows x64 Content, Events and Map & NPC editors.

1. Extract the entire archive into a writable folder.
2. Run `LibreKO.Editors.exe`. Keep both runtime directories, the PCK and Help
   beside it. An SDK is not required for ordinary database editing.
3. Open Settings and select your installed client assets and workspace.
4. Connect through Docker or Connection. Run Compatibility on staging first.
5. Press Help/F1 for production activation and rollback instructions.

No game assets, personal profiles, passwords, dumps or history are included.
Reuse your previous workspace path to retain its history.
